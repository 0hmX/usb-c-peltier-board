Left edge · two independent USB ports

PD power above; RP2040 programming below. CH224K is next to the power connector. USB data protection and isolation stay beside the programming port.

Upper right · Peltier power

Input capacitor bank, MOSFET pair, LT3741 controller, inductor and Kelvin shunt cluster toward the TEC terminal.

Lower left · processor / service

RP2040, external flash, crystal and local decoupling. USB-C-only programming with physical BOOT/RESET access.

Lower right · sensing / cooling

Thermistors and safety comparators separate from the switching stage. Fan converter and connector remain at the right edge.

Review prototype — not fabrication-ready.

Programming USB inhibits both TEC and fan power. No firmware is included. CH224K does not report the adapter’s current capability: qualify a ≥3 A adapter before enabling a load. Routing, thermal analysis, USB current/ESD qualification, component ratings and bench tests remain required. See the repository design notes for all limits.
